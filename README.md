# HTML & JSON Server

A Flask project demonstrating HTTP routing, HTML responses, JSON APIs, and client-server
architecture.

## Features

- HTML pages including /, /about, /projects, /contact
- JSON endpoints including /api/about, /api/projects
- GET and POST methods at /api/contact

## How to Run

1. Install Python.
   
2. Install the dependencies:
   pip install -r requirements.txt

3. Start the application:
   python app.py

4. Visit http://127.0.0.1:5000 in your browser.


## Test the API

- GET /api/about
- GET /api/projects
- GET /api/contact

- POST /api/contact
The POST endpoint returns the submitted JSON data
and a confirmation message.


## This project demonstrates:

- Flask routes and endpoints
- HTTP GET and POST requests
- HTML and JSON responses
- HTTP status codes
- Client-server architecture
